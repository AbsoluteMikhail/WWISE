# Здесь был большой тестовый файл

В оригинальном Audiokinetic Gyms здесь лежит `LargeMedia.wav` размером около 1 ГБ. Он нужен для проверки работы с большими аудиофайлами, а в наших занятиях не используется, поэтому мы его убрали.

Объекты Wwise, которые ссылались на этот файл, используют короткий `ShortMedia_0.wav` как заглушку. Имена и идентификаторы объектов сохранены, чтобы не ломать ссылки на события в Unreal. Это больше не тест большого медиа.

Скрипт `../../GenerateProjectWavFiles.py` в этой копии также не создаёт большой WAV. Оригинальный тест и его генератор доступны в [официальном репозитории Audiokinetic Gyms](https://github.com/audiokinetic/Gyms).
