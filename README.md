# Знакомимся с Wwise в Unreal Engine

Учебный проект, в котором мы с нуля разбираемся, как использовать Wwise в Unreal Engine: от первого звука до интерактивного аудио и акустики помещений. Собираем небольшие примеры своими руками в Blueprints, слушаем результат и проверяем происходящее в Wwise Profiler.

Проект также пригодится саунд-дизайнерам, которые уже знакомы с Wwise, но хотят увереннее работать с Blueprints и связывать звук с игровой логикой. Репозиторий пополняется по мере занятий.

## Что изучаем

- **Первый звук:** AkComponent, Events, Post Ak Event, запуск и остановка воспроизведения.
- **Switch и RTPC:** выбор звукового варианта и передача числовых параметров из игры в Wwise.
- **Источники и слушатель:** Listener, позиционирование в 3D и затухание звука с расстоянием — Attenuation.
- **Отладка:** подключение Wwise Profiler к игре, поиск событий, источников и изменений параметров.
- **Игровая логика:** коллизии и триггеры, переменные, состояния, таймеры и ссылки на объекты в Blueprints.
- **Автоматическое оружие:** состояние IsFiring, повторение выстрелов, окончание очереди и передача боезапаса в RTPC.
- **Акустика помещений:** Rooms, Portals, Geometry и реверберация.
- **Управление AI для звуковых тестов:** временное отключение агрессии и преследования игрока.

Это программа практики: перечисленные темы не означают, что для каждой уже есть законченный пример в текущей версии репозитория.

## С чего начать

Рабочие версии проекта:

| Компонент | Версия |
| --- | --- |
| Unreal Engine | 5.7 |
| Wwise Authoring | 2025.1.11.9262 |
| Wwise Unreal Integration | 2025.1.11.9262.4509 |

Для клонирования нужен [Git LFS](https://git-lfs.com/): большой тестовый звук `LargeMedia.wav` хранится через него. SDK Wwise устанавливается отдельно через Audiokinetic Launcher. После установки Git LFS выполните:

```sh
git lfs install
git clone git@github.com:AbsoluteMikhail/WWISE.git
cd WWISE
```

При обычном клонировании файлы LFS скачиваются автоматически. Если проект уже склонирован без них, выполните `git lfs pull` в корне проекта. Для первого запуска используйте Git clone, а не ZIP-архив репозитория.

1. Установите Unreal Engine и Wwise Authoring соответствующих версий. Через Audiokinetic Launcher интегрируйте Wwise указанной версии в `WWISE.uproject`: это также установит готовые модули плагина под ваш движок. Выберите существующий Wwise-проект `Gyms_WwiseProject/Gyms.wproj`.
2. Запустите **`GenerateSoundBanks.cmd`** двойным щелчком. Скрипт найдёт Wwise указанной версии через `WWISEROOT` или в стандартных папках Audiokinetic и сгенерирует банки для Windows/en_US. Если Wwise установлен в другом месте, укажите папку его установки в переменной окружения `WWISEROOT`.
3. Для редактирования звука откройте `Gyms_WwiseProject/Gyms.wproj` в Wwise. Банки можно также генерировать вручную для **Windows**, выбрав **en_US** и SFX; папка вывода — `Gyms_WwiseProject/GeneratedSoundBanks`.
4. Откройте `WWISE.uproject` в Unreal Engine и учебную карту `Content/WWISE/Levels/Game`.
5. Начните с простого актора с AkComponent: вызовите `Post Ak Event` для события `PostEvent_Event`. Затем попробуйте Switch и RTPC на том же компоненте.

Для каждого упражнения меняйте один параметр, проверяйте результат на слух и смотрите, что приходит в Wwise Profiler. Так проще понять, за что отвечает игровая логика, а за что — настройка звука в Wwise.

## Что лежит в репозитории

| Путь | Содержимое |
| --- | --- |
| `WWISE.uproject` | Проект Unreal Engine |
| `Content/WWISE` | Учебная карта и Blueprints |
| `Content/WwiseAudio` | Ассеты интеграции Wwise: события, параметры и другие объекты |
| `Gyms_WwiseProject` | Локальная учебная копия Wwise-проекта из Audiokinetic Gyms |

Названия событий для первых упражнений, детали переноса и генерации банков описаны в [README учебной копии Wwise](Gyms_WwiseProject/README-Учебный-проект.md).

## Что храним в Git

В репозитории храним карту, Blueprints, ассеты `Content/WwiseAudio`, настройки проекта, Wwise Work Units и исходные звуки из `Originals` и `ExternalSources`. Файлы `Content/__ExternalActors__` — часть карты, их тоже нужно коммитить.

Кэши, временные файлы, локальные настройки редакторов и `Gyms_WwiseProject/GeneratedSoundBanks` исключены через `.gitignore`. После клонирования генерируйте банки по инструкции выше; повторяйте генерацию после изменений звука в Wwise.

SDK в `Plugins/WwiseSoundEngine/ThirdParty` исключён из Git и Git LFS. Audiokinetic Launcher устанавливает его при интеграции Wwise в проект — этот шаг обязателен после клонирования. Исходный `LargeMedia.wav` сохранён в LFS: это большой тестовый файл Gyms, а не кэш.

[**Audiokinetic / Gyms — официальный репозиторий Wwise Gyms**](https://github.com/audiokinetic/Gyms)

Здесь собраны рабочие примеры интеграции Wwise с Unreal Engine и Unity. Используйте их для самостоятельного изучения: выберите нужную механику, запустите пример, проследите связь игровой логики с объектами Wwise и повторите её в своём проекте.
